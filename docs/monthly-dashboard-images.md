# Imagens do dashboard mensal

Geradas com a ferramenta integrada **imagegen**. Os PNGs originais foram preservados no diretório de imagens geradas do Codex. As cópias usadas pelo aplicativo foram reduzidas para 768 × 512 e convertidas em WebP (qualidade 88), sem alterar a composição.

- `public/art/monthly-credit.webp` — 19.584 bytes.
- `public/art/monthly-pix.webp` — 27.752 bytes.

O movimento é aplicado pelo aplicativo, com suporte a `prefers-reduced-motion`. Valores e rótulos são texto HTML, não fazem parte das imagens.

## Prompt do cartão

Use case: product-mockup. Generate a premium photorealistic 3D editorial render for a Brazilian personal finance dashboard, landscape 3:2 composition. Subject: one beautiful physical credit card floating at a gentle 3/4 angle above a dark teal satin plinth, with a second translucent glass card behind it, brushed metallic chip, subtle embossed abstract wave, immaculate rounded edges. This must look like a luxury studio product photograph, NOT a flat icon, not a UI mockup. Palette deep midnight teal #0c2934, turquoise #14b8a6, mint edge light, soft cyan. Background is seamless deep teal with diffused atmospheric glow, tasteful shadows and realistic depth. Card centered with generous breathing room. No text, no digits, no logos, no watermark. Final image asset will be used in a real local React app.
